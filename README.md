# Hybrid RF-VLC Green Communication Simulation (IEEE Research Based)

## Overview

This repository reproduces the simulation results of the IEEE research paper:

**Green and Safe 6G Wireless Networks: A Hybrid RF-VLC Approach**

The project compares:

* RF (WiFi) Communication
* Visible Light Communication (VLC)
* Hybrid RF + VLC Communication

## Simulations Included

* SINR vs Distance
* Energy Efficiency vs Distance
* Battery Lifetime vs Distance
* SAR vs Skin Depth
* Complexity Analysis
* Incident & Absorbed Power Density

## Technologies Used

* Matlab
* NumPy
* Matplotlib

## Output

All figures are automatically saved in the `results/` folder as high-resolution PNG images.

## Research Highlights

* 37% improvement in energy efficiency.
* 59.6% reduction in SAR.
* Battery lifetime increased by approximately 7 hours.
* Lower power density and temperature elevation compared to conventional RF communication.
